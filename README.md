# riverpod_tools

Blank Melos workspace.

## Getting started

1. Install Melos (one-time):
   - `dart pub global activate melos`
2. From this folder:
   - `dart pub get`
   - `melos list`

## Add packages

Create packages under `packages/` (for example `packages/my_package`). Melos will pick them up via `packages/**`.
